# Ressources Transversales (Communes N1, N2, N3)

> **Périmètre :** Ressources méthodologiques universelles partagées par les trois niveaux du cursus Solicode :
> - **N1 — Découvrir**
> - **N2 — Prototyper**
> - **N3 — Développer / Réaliser**

---

## 1. Cadre des Trois Niveaux

| Niveau | Désignation | Objectif d'Apprentissage | Modalité Principale |
| :---: | :--- | :--- | :--- |
| **N1** | **Découvrir** | Acquisition guidée des fondamentaux pas-à-pas | Tutoriels pas-à-pas (Imitation guidée) |
| **N2** | **Prototyper** | Structuration du code (POO, 3-tiers, UML) | Prototypes dirigés (Adaptation) |
| **N3** | **Développer (Réaliser)** | Transposition en autonomie, frameworks, TDD, SOLID, Scrum | Mini-projets & Projets complets |

---

## 2. Démarche Pédagogique Commune

Quel que soit le niveau, chaque bloc d'apprentissage applique le cycle actif :
$$\text{Comprendre} \longrightarrow \text{Reproduire} \longrightarrow \text{Expérimenter} \longrightarrow \text{Réaliser} \longrightarrow \text{Réutiliser}$$

- **Règles d'or rédactionnelles :**
  - Français simple (A1–A2), phrases courtes, verbes à l'impératif direct.
  - Glossaire concis d'une ligne pour tout terme technique introduit.
  - Livrable obligatoire sur GitHub ou fichier Markdown (zéro capture d'écran).
