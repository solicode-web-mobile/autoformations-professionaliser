# Domaines Techniques — Niveau N3 (Développer / Réaliser)

> Cet espace accueille les fiches didactiques des domaines techniques du **Niveau N3**.

## Organisation des Domaines N3

Chaque fiche domaine définira :
1. Le code du domaine N3 et sa compétence associée.
2. La stack et les outils concernés (ex: Laravel, Alpine.js, Pest/PHPUnit, Docker, Scrum).
3. Les contraintes architecturales et les critères d'acceptation professionnelle.
4. Les formats de code et les modèles de livrables attendus.
