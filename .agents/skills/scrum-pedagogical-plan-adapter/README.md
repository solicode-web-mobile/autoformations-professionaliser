# Skill `scrum-pedagogical-plan-adapter`

Analyse, calibre et simplifie l'organisation pédagogique d'une formation en sprints Scrum de 80h sans surcharge cognitive.

## 1. À quoi sert ce Skill ?
- Auditer et équilibrer le découpage pédagogique par session/sprint.
- Garantir le calibrage temporel strict de 80h (10 jours x 8h).
- Détecter et éliminer les tâches inutiles ou redondantes.

## 2. Prompts Types d'Invocation
```markdown
@[.agents/skills/scrum-pedagogical-plan-adapter/SKILL.md] Analyse le plan de sprint pour la session S1 et ajuste le calibrage.
```
