# Skill `sync-theme`

Pilote la synchronisation du socle technique partagé (Core Theme) avec `autoformations-core-theme`.

## 1. À quoi sert ce Skill ?
- Pousser (`push_theme.ps1`) ou récupérer (`pull_theme.ps1`) les composants communs du thème Just the Docs.
- Garantir la conformité avec le fichier de configuration `theme-sync.json`.

## 2. Prompts Types d'Invocation
```markdown
@[.agents/skills/sync-theme/SKILL.md] Synchronise les modifications du thème avec le dépôt central.
```
