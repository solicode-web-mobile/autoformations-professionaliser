# Skill : revision-et-change-skills

> **Rôle :** Analyse les remarques du concepteur et adapte les documents de session et l'écosystème de skills  
> **Documentation :** Colocalisée à la racine du skill

---

## 1. Description & Cas d'Usage
Ce skill intervient lors des révisions interactives avec le concepteur pédagogique :
- Analyse des sélections et retours critiques sur les sessions ou plans de formation.
- Génération d'artéfacts de révision interactifs (`RequestFeedback: true`).
- Synchronisation des règles et compétences locales associées.

---

## 2. Prompts d'Invocation Types
- *"Analyse mes remarques sur le flux de travail et propose la révision des skills"*
- *"Applique les modifications validées sur les compétences et le plan de session"*
