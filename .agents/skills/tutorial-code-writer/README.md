# Skill : tutorial-code-writer

> **Rôle :** Rédacteur technique de code incrémental pas-à-pas (`UA-Tuto`)  
> **Écosystème :** `tutorial-*-writer`  
> **Master Skill :** [tutorial-writer](../tutorial-writer/SKILL.md)  
> **Niveau cible :** N3 (Développer / Réaliser)

Ce skill conçoit et rédige des tutoriels d'apprentissage de code pur, transformant de façon incrémentale l'état $E_{n-1}$ vers $E_n$ pour guider les apprenants vers le livrable applicatif final.
