# Skill `dev-n3`

Développeur et coach technique sur la stack Niveau N3 (Laravel, Alpine.js, TDD, principes SOLID et gestion agile Scrum).

## 1. À quoi sert ce Skill ?
- Accompagner l'implémentation et la refactorisation de code Laravel / Alpine.js.
- Conduire des tests automatisés (TDD, cycle Red-Green-Refactor).
- Auditer l'architecture logicielle selon les principes SOLID et conventions PSR-12.
