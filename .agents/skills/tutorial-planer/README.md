# Skill `tutorial-planer`

Architecte de la progression pédagogique : conçoit les plans de réalisation par session, crée les entités Jekyll manquantes et initialise les stubs.

## 1. À quoi sert ce Skill ?
- Concevoir la chaîne continue d'apprentissage ($E_{n-1} \to E_n$) sans rupture cognitive.
- Équilibrer les titres de tutoriels (un seul objectif concret, zéro entité métier).
- Créer automatiquement les entités manquantes (`_sessions/`, `_domaines/`, `_uas/`) et les stubs de tutoriels (`en_construction: true`).

## 2. Prompts Types d'Invocation
```markdown
@[.agents/skills/tutorial-planer/SKILL.md] Conçois et planifie la progression des tutoriels pour la session S1.
```
