# Skill : tuto-notion-writer

## Description
Le skill **`tuto-notion-writer`** conçoit, structure et rédige les tutoriels de notions théoriques, syntaxiques ou conceptuelles isolées (**`type: "tuto-notion"`**) pour l'EFP.

Membre de l'écosystème de rédaction sous la gouvernance de **`tuto-writer`**, il garantit l'isolation conceptuelle, la règle des 20% fondamentaux et l'absence d'exigences superflues (zéro Marp).

---

## 1. Rôle & Responsabilités
- **Rédaction de Notions Pures :** Fiches conceptuelles (ex: Découverte de Blade, Expressions régulières, Principes SOLID).
- **Livrables Dédiés :** Fiche d'apprentissage et journal de commandes dans `tutoriels/` (sans toucher à `src/`).
- **Allègement Didactique :** Interdiction des présentations Marp.

---

## 2. Prompts Types pour l'Invoquer
- *« Rédige le tutoriel de notion sur la syntaxe des directives Blade en suivant le standard tuto-notion. »*
- *« Structure une fiche de notion théorique sur les principes SOLID sans impacter le projet d'imitation. »*
