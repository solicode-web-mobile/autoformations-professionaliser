# Skill `dev-jekyll`

Développe, optimise et maintient l'architecture frontend, les layouts, les assets CSS/JS et les composants interactifs du site Jekyll Just the Docs.

## 1. À quoi sert ce Skill ?
- Maintenir et faire évoluer les layouts (`_layouts/`) et inclusions (`_includes/`).
- Styliser les composants en CSS modulaire sous `assets/css/` (zéro CSS inline).
- Développer et maintenir les scripts interactifs (injecteur interactif, filtres Liquid `jsonify`).

## 2. Prompts Types d'Invocation
```markdown
@[.agents/skills/dev-jekyll/SKILL.md] Ajuste le layout de présentation pour les tutoriels de code.
@[.agents/skills/dev-jekyll/SKILL.md] Ajoute une classe CSS pour styliser les alertes personnalisées.
```
